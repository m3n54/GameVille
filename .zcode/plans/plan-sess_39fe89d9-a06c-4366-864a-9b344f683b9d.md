# Plan: Rombak Gameplay GameVille — 3 Permintaan Utama + 3 Ekspansi

## Konteks hasil eksplorasi
1. **Sea Battle**: penempatan manual memang tidak pernah diimplementasi (audit M-7) — engine hanya punya `autoPlace`. Titik integrasi: varian `GameAction` baru di `shared/types.ts:52-68`, branch baru di `server/src/games/sea-battle.ts` (sejajar `autoPlace` line 107), fase setup FE di `SeaBattleContainer.tsx:180-197`, `Grid.tsx` reusable via `onCellClick`. Catatan: case `shipsPlaced` di socketHandlers hanya broadcast state — handler FE-nya dead code, perlu emit `game:action` ditambahkan.
2. **Dadu 3D**: overlay angka sudah ada tapi baru muncul setelah 1.950ms animasi (`SPIN_MS` 1700 + `SETTLE_MS` 250); komponen terisolasi (props `value/rolling/onRoll/disabled`, tombol di dalam komponen); SFX dipicu dari container — tidak tersentuh penggantian.
3. **Animasi pion**: semua konstanta di satu tempat `usePawnAnim.ts:10-13` — `HOP_MS_PER_TILE` 600, `HOP_DELAY_MS` 80, `SLIDE_MS_PER_TILE` 400, `SLIDE_MAX_MS` 4000 (dipakai timer glow di container — harus dinaikkan bersamaan).
4. **Minesweeper**: modal tap-to-choose SUDAH ADA (Anda belum sempat test) — celah sebenarnya: kotak berbendera tidak bisa dibuka modalnya lewat klik kiri (`MinesweeperGrid.tsx:42` guard `state !== 'hidden'`), sehingga di iOS (tanpa klik kanan) bendera tidak bisa dilepas.

## Keputusan Anda
Tray+klik papan (Sea Battle) · kartu wajah+angka besar (dadu) · pertahankan modal+perbaiki unflag (Minesweeper) · plus: turn timeout, rematch 1-klik, papan acak. Default aktif: jarak kapal ikut aturan auto (buffer 1 sel), tombol Auto tetap, reset diizinkan, `placeShips` atomik via Konfirmasi, angka dadu tampil segera, tombol lempar menyatu, Dice3D dihapus, kecepatan animasi 850/140/650ms, lock giliran saat animasi, Hangman tak disentuh, Vitest untuk semua logika engine baru.

## Workstream A — Sea Battle: penempatan kapal manual
- `shared/types.ts`: varian `{ type: 'placeShips'; payload: { ships: { cells: [number,number][] }[] } }` — client hanya kirim koordinat; `type`/`hits` dibangun server.
- `sea-battle.ts`: ekstrak `canPlaceShip(cells, grid, { requireBuffer })` dari loop autoPlace; branch `placeShips`: guard fase setup + pemain valid + fleet masih kosong; validasi tepat 5 kapal multiset `[4,3,3,2,1]`, kontigu horizontal/vertikal, dalam 10×10, tanpa overlap, buffer 1 sel; sukses → tulis grid/ships, emit `shipsPlaced {playerId}`, faktorkan transisi `playing`/`turnChange` jadi helper bersama autoPlace.
- `socketHandlers.ts` case `shipsPlaced`: tambah emit `game:action { type:'shipsPlaced', playerId }` (menghidupkan handler FE yang dead code).
- FE: tray sisa kapal + toggle rotasi H/V + grid sendiri interaktif saat setup (klik = letakkan, klik kapal draft = ambil kembali) + "Atur Ulang" + "🎲 Acak" (tetap) + "✅ Konfirmasi" saat 5 kapal terpasang → emit atomik.
- Test Vitest: valid, multiset salah, overlap, pelanggaran buffer, re-place ditolak, dua pemain selesai → `playing`.

## Workstream B — Ular Tangga: dadu 2D + animasi + papan acak
- `Dice2D.tsx` baru: kontrak prop identik; kartu wajah datar pip besar; saat `rolling` → goyang spring + gulir digit; hasil server tiba → angka besar segera + flash. Hapus `Dice3D.tsx` + ekspor `index.ts`; `useDiceRoll` dihapus bila tak terpakai (dicek saat eksekusi).
- `usePawnAnim.ts`: 600→850, 80→140, 400→650, `SLIDE_MAX_MS` 4000→6500 (glow timer otomatis mengikuti karena mengimpor konstanta).
- Lock giliran saat animasi (L-2): container tandai `animating` saat segments dibuat, lepas setelah `SLIDE_MAX_MS`; dadu disabled selama itu.
- Papan acak: `generateBoardLayout()` mengganti konstanta SNAKES/LADDERS di `createInitialState` — 10 ular + 9 tangga, validitas: tanpa konflik tile, tidak menyentuh 0/99, kepala > ekor, kaki < puncak. FE sudah layout-agnostic.
- Test Vitest: N-sampel layout selalu valid; permainan tetap bisa dimenangkan.

## Workstream C — Minesweeper: unflag mobile
- Longgarkan guard klik-kiri agar kotak berbendera membuka modal; modal kontekstual menampilkan tombol primer "🚩 Lepas Bendera"; teks bantuan diganti ("Klik kiri: pilih aksi · Klik kanan: bendera").

## Workstream D — Turn timeout anti-AFK (M-5)
- `GameInstance.lastActionAt` di-update tiap `handleAction` sukses + saat start; sweeper 10 dtk: game aktif + idle > 90 dtk → server mainkan aksi netral untuk pemain current: Ular Tangga auto-roll; Minesweeper auto-`pass` (aksi `pass` kini dibolehkan di kedua mode); Sea Battle `pass` server-synthetic (tanpa tombol FE).
- Interaksi H3: grace 60 dtk < timeout 90 dtk — forfeit mendahului timeout untuk pemain yang hilang.
- Test Vitest dengan jam sintetis: timeout memicu aksi tepat sekali; aksi normal me-reset timer.

## Workstream E — Rematch 1-klik
- Event `game:rematch` (host-only, room `finished`): reset room, set semua `isReady = true`, jalankan jalur `game:start` existing (validasi komposisi G1 tetap) dengan gameType sama.
- FE layar pemenang: tombol "🔁 Main Lagi" (host), non-host melihat "Menunggu host…" dan masuk otomatis via `game:started`.
- Test integrasi: rematch → `game:started` sama, match baru berjalan.
